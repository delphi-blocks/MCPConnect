MCPConnect 2.0.0

A Delphi library for building Model Context Protocol servers: attribute-driven tools, resources and prompts over JSON-RPC 2.0, the same configuration on WebBroker, Indy and stdio, and the metrics on this page built in.

This deployment is a todo-list MCP server and the dashboard its operators watch it with. POST /mcp gives MCP clients the todo tools and nothing else; every call they make is recorded by a middleware and shows up here, and on /metrics for anything that would rather parse JSON. Embarcadero's WebStencils renders this page on the server from the metrics of the process it runs in — no second service, no CORS, and no build step on the way to your screen.
